## How to Capture Full Screenshots in Your Browser (10 Seconds)

To capture full, pixel-perfect screenshots of any section:

1. Open your live portfolio at `https://astikdas11.github.io/myPortfolio/` (or locally at `http://localhost:5173`).
2. Press **`F12`** (or `Ctrl + Shift + I`) to open Developer Tools.
3. Press **`Ctrl + Shift + P`** to open the Command Menu.
4. Type **`Capture screenshot`** or **`Capture full size screenshot`** and press **Enter**.
5. Save the downloaded image directly into this directory using the corresponding filename above (e.g. `01-hero-section.png`).
